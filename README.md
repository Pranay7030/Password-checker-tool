# Password Checker Tool - By Pranav Meshram
### Bhandara Cyber Tool - 100% Working

Ye tool Laptop, Linux aur Termux teeno me chalega.

KALI LINUX ME:
  sudo apt update && sudo apt install python3-tk git -y
  git clone https://github.com/Pranay7030/Password-checker-tool.git
  cd Password-checker-tool
  pip3 install customtkinter
  python3 Main.py

TERMUX ME:
  pkg update && pkg install python git -y
  git clone https://github.com/Pranay7030/Password-checker-tool.git
  cd Password-checker-tool
  python Main.py

WINDOWS ME:
  pip install customtkinter
  python Main.py
